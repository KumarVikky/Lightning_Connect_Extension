Explore the workspace

One launch point.
Many ways to move work forward.

Lightning Connect organizes Salesforce data, metadata, and developer workflows around the context you are already working in.

LauncherData exportData importMetadataDeveloper console

01 · Salesforce launcher

Start from the page you are already on.

The in-page drawer surfaces searchable objects and users, organization context, session status, and quick paths to the workspace tools.

  • Open direct workspace entry points
  • Browse object and record context
  • See connected organization details

02 · Data export & view

From object discovery to usable data.

Inspect objects and fields, construct SOQL queries with editor assistance, review paged results, and export or copy data in practical formats.

  • Object and field explorer
  • SOQL tabs, suggestions, validation, and history
  • CSV and Excel export or copy actions
  • Record and field inspection in Data View

03 · Data import

Prepare changes before they reach your org.

Bring in records manually, from pasted tabular data, or from CSV and Excel files. Map columns, validate staged rows, select permitted operations, and review results.

  • Create, update, upsert, or delete where access permits
  • Field mapping and picklist-aware validation
  • Editable staged rows and per-row outcomes
  • Reusable mappings stored locally in the browser

04 · Download metadata

Build focused packages, without the busywork.

Discover metadata types and components, create a precise selection, inspect available dependencies, generate package.xml, and download a Metadata API ZIP.

  • Searchable metadata discovery
  • Component selection and package queue
  • Generated package.xml and saved local configurations
  • Retrieval status and recent download history

05 · Developer console

Keep source, comparisons, and developer tasks in one view.

Work with Salesforce files in a Monaco-based editor, compare changes, use local scratch files deliberately, and run supporting developer workflows.

⌘

Explore & edit

⇄

Compare with context

Review a file against its org version or compare two files side by side before proceeding.

⇩

Download selected metadata as a ZIP or retrieve individual files where the type supports it.
