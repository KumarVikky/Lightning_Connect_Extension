Latest release · v1.1

More polished, more consistent.

Lightning Craft v1.1 refines the workspace and the tools you use every day, with improvements to component creation, editing, navigation, and Salesforce access.

01

Choose the right Salesforce API version

Developer Console creation dialogs load the available API versions from the connected Salesforce org. The version you choose is used when creating or deploying supported components.

02

Clearer editing for Local Files

Local Files use their file type to select the editor language, bringing syntax colors to supported files while you work on scratch content.

03

Keyboard-friendly dialogs

Move between modal action buttons with the left and right arrow keys in Developer Console, Settings, data tools, metadata dialogs, and drawer confirmations.

04

Focused Salesforce access

Salesforce origin checks were strengthened and extension permissions were streamlined for the supported Salesforce workflows.

05

A more consistent Lightning Craft experience

Branding and small interface details were refined across the launcher, Developer Console, and supporting pages.

Initial release · v1.0

A connected toolkit for Salesforce teams.

Version 1.0 is designed to reduce context switching while keeping important actions visible, reviewable, and grounded in your active Salesforce session.

  • Salesforce-native launcher. Open the extension directly from supported Salesforce pages and keep your current org context in view.
  • Data Export. Browse objects and fields, build SOQL queries, inspect results, and export or copy data in practical formats.
  • Data Import. Stage CSV, Excel, pasted, or manually entered records, map fields, validate rows, and review operations before execution.
  • Data View. Inspect records and field details with a focused view for understanding Salesforce data in context.
  • Download Metadata. Discover metadata types, select components, review dependencies, generate package.xml, and download Metadata API ZIP packages.
  • Developer Console. Browse supported source, edit files, compare changes, work with local scratch files, and run developer workflows.
  • Local-first preferences. Keep settings, query history, mappings, package configurations, and Local Files in the browser profile where you use the extension.
  • Review-oriented workflows. Use validation, staging, selection, and result views to make informed changes in the connected org.
  • Built-in documentation and support. Find product guidance, privacy details, troubleshooting help, and a direct path to report bugs.
